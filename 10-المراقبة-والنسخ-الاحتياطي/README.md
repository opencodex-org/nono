# المراقبة والنسخ الاحتياطي

## راقب

- توفر الموقع وواجهة API.
- زمن الاستجابة ومعدل الأخطاء.
- انتهاء النطاق والشهادة.
- فشل نشر CI/CD.
- تغييرات DNS غير المتوقعة.
- استخدام الموارد وتكلفة الاستضافة.

## النسخ الاحتياطي

احتفظ بنسخ دورية من قاعدة البيانات، إعدادات DNS، ملفات البنية التحتية، وتعليمات الاستعادة. اختبر الاستعادة فعلياً؛ وجود نسخة غير قابلة للاستعادة ليس خطة احتياطية.
