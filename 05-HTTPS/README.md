# HTTPS

## متطلبات الإطلاق

- شهادة TLS صالحة للاسم الجذر و`www` وأي نطاقات فرعية مستخدمة.
- تحويل كل طلبات HTTP إلى HTTPS.
- تجديد تلقائي للشهادة مع تنبيه عند الفشل.
- فحص عدم وجود محتوى مختلط Mixed Content.
- اختبار النطاقات من متصفحات وأجهزة متعددة.

## قائمة فحص

- [ ] الشهادة غير منتهية.
- [ ] اسم المضيف موجود في الشهادة.
- [ ] HTTP يعيد توجيهاً إلى HTTPS.
- [ ] ملفات JavaScript وCSS تعمل عبر HTTPS.
- [ ] ملفات تعريف الارتباط الحساسة تحمل `Secure` و`HttpOnly` عند الحاجة.
