# النطاقات المدفوعة

## خطوات الشراء الآمن

1. اختر مسجلاً موثوقاً وفعّل المصادقة الثنائية.
2. افحص سعر التسجيل وسعر التجديد وسعر النقل، لا سعر السنة الأولى فقط.
3. تحقق من رسوم الخصوصية، والاسترداد، وقفل النقل.
4. سجّل بيانات المالك الصحيحة وفق متطلبات المسجل.
5. فعّل التجديد التلقائي مع وسيلة دفع محدثة.
6. احفظ رمز النقل في مدير أسرار، وليس في Git.
7. احتفظ بنسخة من سجلات DNS وخطة نقل بديلة.

## اختيار الامتداد

اختر الامتداد وفق جمهور المشروع وبلده ونوع النشاط. لا تفترض أن كل امتداد مناسب للبريد أو الخدمات الحساسة، وتحقق من سياسات السجل قبل الشراء.
