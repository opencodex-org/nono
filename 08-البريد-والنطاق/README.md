# البريد المرتبط بالنطاق

## السجلات المهمة

- **MX:** يحدد خوادم استقبال البريد.
- **SPF:** يحدد الجهات الم��موح لها بالإرسال.
- **DKIM:** يوقع الرسائل تشفيرياً.
- **DMARC:** يحدد سياسة الرسائل التي تفشل في التحقق.

ابدأ بسياسة DMARC للمراقبة مثل `p=none`، راقب التقارير، ثم شدد السياسة تدريجياً بعد التأكد من أن جميع مصادر الإرسال موثقة. لا تنس خدمات النماذج والتنبيهات والفواتير.

لا تنشر مفاتيح DKIM الخاصة. المفتاح العام فقط يوضع في DNS.
