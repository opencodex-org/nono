# استضافة المواقع الثابتة

## بنية عامة

```text
المستخدم -> DNS -> CDN/استضافة ثابتة -> ملفات HTML/CSS/JS
```

## خطوات النشر

1. أنشئ مشروعاً في منصة الاستضافة.
2. اربط مستودع Git أو ارفع ملفات البناء.
3. حدد أمر البناء ومجلد الناتج، مثل `dist` أو `build`.
4. أضف النطاق المخصص من لوحة المنصة.
5. أضف سجلات DNS التي تظهرها المنصة حرفياً.
6. انتظر التحقق ثم اختبر HTTPS والتوجيهات.

لا تنس ضبط إعادة الكتابة لتطبيقات SPA بحيث يعود المسار غير المعروف إلى `index.html` حسب تعليمات المنصة.
