# أساسيات النشر

## دورة النشر الفعلية

1. تجهيز الكود واختباره محلياً.
2. إنشاء بيئة تجريبية منفصلة عن الإنتاج.
3. اختيار الاستضافة والنطاق.
4. ربط DNS بالاستضافة.
5. تفعيل HTTPS.
6. اختبار الموقع من شبكة وأجهزة مختلفة.
7. إطلاق الإنتاج مع خطة تراجع.
8. مراقبة الأخطاء والأداء والتجديدات.

## البيئات

- **محلية:** للتطوير فقط.
- **تجريبية:** لاختبار التكامل قبل الإطلاق.
- **إنتاج:** البيانات والخدمة الفعلية للمستخدمين.

لا تستخدم نطاق الإنتاج لاختبار تغييرات غير مكتملة.
