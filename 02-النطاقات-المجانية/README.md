# النطاقات المجانية

النطاق المجاني الحقيقي يعني أن جهة ما تمنحك التسجيل أو الاسم دون رسوم مباشرة، لكنه قد يتضمن شروطاً أو قيوداً أو تجديداً يدوياً أو إعلانات أو قابلية سحب الاسم. راجع الشروط الحالية للجهة المسجلة قبل الاعتماد عليه.

## بدائل مجانية عملية

- نطاق فرعي مجاني من منصة الاستضافة، مثل `<project>.pages.example` أو `<project>.host.example`.
- نطاق فرعي من نطاق تملكه أنت، مثل `<app>.example.com`.
- نطاقات اختبار محلية مثل `localhost` أو أسماء داخلية للشبكة.

## قبل الاعتماد على نطاق مجاني

- هل هو نطاقاً أعلى مجانياً أم نطاقاً فرعياً؟
- هل يسمح بالاستخدام التجاري؟
- هل يتطلب تجديداً دورياً؟
- هل يدعم نقل النطاق وDNSSEC وHTTPS؟
- هل يمكن فقدانه عند توقف الحساب؟
- هل سمعة الامتداد مناسبة للبريد والإعلانات؟

للمشاريع الجادة، استخدم نطاقاً مدفوعاً تملكه أنت، ويمكن إبقاء النطاق الفرعي المجاني للمعاينة.
