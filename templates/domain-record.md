# قالب توثيق نطاق

- اسم النطاق: `<example.com>`
- نوعه: مجاني / مدفوع
- المسجل: `<registrar>`
- تاريخ التسجيل: `<YYYY-MM-DD>`
- تاريخ التجديد: `<YYYY-MM-DD>`
- مزود DNS: `<provider>`
- مزود الاستضافة: `<provider>`
- مسؤول النظام: `<team-or-role>`
- رابط لوحة المراقبة: `<url>`
- ملاحظات النقل والتراجع: `<notes>`

لا تضع اسم المستخدم أو كلمة المرور أو مفتاح API هنا.
