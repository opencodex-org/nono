# أمان النطاق والنشر

- فعّل المصادقة الثنائية للمسجل والاستضافة وGit.
- استخدم قفل النطاق وقفل النقل إن توفر.
- امنع تعديل DNS من حسابات غير ضرورية.
- خزّن الأسرار في Secret Manager أو متغيرات بيئة محمية.
- راقب تغييرات DNS وتسجيلات الدخول.
- حدّث بيانات الاتصال والتنبيهات الخاصة بالانتهاء.
- لا تستخدم حساباً مشتركاً لشراء النطاق أو إدارة الإنتاج.
- طبّق أقل صلاحية ممكنة على CI/CD.
- افحص المستودع بحثاً عن أسرار قبل كل نشر.
