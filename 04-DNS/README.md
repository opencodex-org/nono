# DNS

## السجلات الأساسية

| النوع | الاستخدام | مثال |
|---|---|---|
| A | ربط اسم بعنوان IPv4 | `@ -> <IPV4>` |
| AAAA | ربط اسم بعنوان IPv6 | `@ -> <IPV6>` |
| CNAME | اسم مستعار لاسم آخر | `www -> <target>` |
| MX | خوادم البريد | `@ -> <mail-host>` |
| TXT | التحقق وSPF وغيرها | `@ -> <verification>` |
| NS | خوادم DNS المعتمدة | حسب المسجل |

## خطة ربط موقع

- اجعل `www` واسم الجذر يتجهان إلى الوجهة المقصودة.
- استخدم TTL منخفضاً أثناء النقل، ثم ارفعه بعد الاستقرار.
- احذف السجلات القديمة التي قد تسبب تعارضاً.
- انتظر انتشار DNS؛ لا تعتبر تأخره فشلاً فورياً.
- تحقق باستخدام أدوات DNS من أكثر من موقع.

لا تضع سجلات MX أو TXT عشوائية؛ سجل خاطئ قد يعطل البريد أو التحقق.
