# استضافة التطبيقات وواجهات API

## قبل الإنتاج

- استخدم متغيرات بيئة خارج الكود.
- اجعل التطبيق يستمع على المنفذ الذي توفره المنصة.
- أضف endpoint للصحة مثل `/health` دون كشف أسرار.
- نفذ migrations بطريقة قابلة للتراجع.
- حدد timeouts وحدود الذاكرة ومعدل الطلبات.
- افصل قاعدة بيانات الإنتاج عن التجريب.

## النطاقات

يمكن استخدام:

- `app.<domain>` للواجهة.
- `api.<domain>` للواجهة البرمجية.
- `admin.<domain>` للوحة الإدارة مع حماية إضافية.

قيّد CORS إلى أصول معروفة، ولا تستخدم `*` مع بيانات الاعتماد.
