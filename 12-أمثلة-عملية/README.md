# أمثلة عملية

## مثال: موقع ثابت بنطاق فرعي مجاني

```text
اسم المشروع: <project>
الرابط المؤقت: <project>.<hosting-domain>
البناء: <build-command>
مجلد الناتج: <dist>
```

## مثال: موقع إنتاج بنطاق مدفوع

```text
النطاق: <example.com>
www: CNAME -> <hosting-target>
الجذر: A/ALIAS -> <hosting-target-or-ip>
التطبيق: app.<example.com>
الواجهة البرمجية: api.<example.com>
البريد: MX -> <mail-provider>
```

## خطة تراجع

احتفظ بآخر إصدار ناجح، ولا تحذف إعدادات DNS القديمة مباشرة. عند فشل الإصدار، أعد توجيه الاستضافة إلى الإصدار السابق، ثم افحص السجلات قبل إعادة المحاولة.

هذه أمثلة تعليمية؛ استبدل القيم حسب مزود الاستضافة والمسجل الفعلي.
