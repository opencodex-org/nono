# النشر الفعلي والنطاقات

هذا المستودع يجمع أدلة عملية للنشر الحقيقي للمواقع والتطبيقات باستخدام نطاقات مجانية ومدفوعة، مع التركيز على DNS وHTTPS والتحقق قبل الإطلاق.

## المجلدات

- `01-أساسيات-النشر/` — خطة الإطلاق والبيئات.
- `02-النطاقات-المجانية/` — الخيارات المجانية وحدودها.
- `03-النطاقات-المدفوعة/` — التسجيل والتجديد والخصوصية.
- `04-DNS/` — السجلات وربط النطاق بالاستضافة.
- `05-HTTPS/` — الشهادات والتوجيه الآمن.
- `06-استضافة-ثابتة/` — نشر المواقع الثابتة.
- `07-استضافة-تطبيقات/` — نشر تطبيقات الخادم وواجهات API.
- `08-البريد-والنطاق/` — إعداد البريد وSPF وDKIM وDMARC.
- `09-الأمان/` — حماية الحسابات والنطاقات.
- `10-المراقبة-والنسخ-الاحتياطي/` — التشغيل بعد الإطلاق.
- `11-قوائم-التحقق/` — قوائم جاهزة قبل وبعد النشر.
- `12-أمثلة-عملية/` — سيناريوهات تطبيقية قابلة للتعديل.

> لا تُدخل كلمات المرور أو مفاتيح API أو بيانات الدفع في المستودع. استبدل القيم بين `<...>` بقيمك، وتحقق من شروط كل مزود قبل الاستخدام.
